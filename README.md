# Unimate · 微信小程序

Unimate 的独立原生微信小程序实现。它不会改动 Android 主工程，使用微信小程序页面、存储和交互能力重新实现校园学习生活的核心流程。

## 当前功能

- 按周查看课表，左右滑动或点击箭头切换周次
- 自动定位本周，高亮今天和当前节次
- 显示下一节课及倒计时
- 查看课程时间、周次、教室、教师和备注
- 新增、编辑和删除课程，自定义上课周次与颜色
- 设置学期第一周周一、总周数、是否显示周末和每节课时间
- 首次打开自动载入脱敏示例课表
- 记事新增、编辑、完成状态与二次确认删除
- Uni 本机规则问答、最近 100 条历史记录、系统键盘语音输入入口
- 北京化工大学校园服务九宫格与平台能力提示
- “我的”页数据统计、课表设置和二次确认清理
- 全部数据保存到微信本地缓存，当前版本不需要服务器

## 在微信开发者工具中运行

1. 打开微信开发者工具，选择“导入项目”。
2. 选择本仓库目录。
3. 测试时可直接使用配置中的测试 AppID；正式发布前，把 `project.config.json` 的 `appid` 改为你的小程序 AppID。
4. 点击“编译”。

项目使用微信原生小程序语法，无第三方运行时依赖，也不需要执行 `npm install`。

## 本地测试

需要 Node.js 18 或更高版本：

```bash
npm test
```

测试覆盖周次/日期计算、单双周解析、稳定课程配色，以及项目配置和页面文件完整性。

## 数据说明

本项目不读取或保存教务系统密码。课程、设置、记事与 Uni 历史通过 `wx.setStorageSync` 保存在当前微信客户端内。清理小程序数据或卸载后，本地数据会被删除。

```text
utils/             日期、周次、配色、本地存储和二次确认
tests/             Node.js 单元与结构测试
```
